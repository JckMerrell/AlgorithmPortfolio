## Running Instructions
Language: C++ 
All dependencies included in files
Compile from terminal: g++ main.cpp WeightedInterval.cpp DiscreteKnapsack.cpp MaximumRemovals.cpp -o Part3
Ensure TestCases folder is local to executable
TestCases file names are hardcoded into fileInput3. To add or rename files, modify the relevant vector in fileInput3. 
Run ./Part3. All tests for all tasks will be run. Task B requires manual input of fuel budget, suggestions are provided.

Input formats:
1. Part A
   One delivery per line, one file per test case
   ID START_INT FINISH_INT VALUE_INT
2. Part B
   One Delivery per line, one file per test case
   ID FUEL_COST_INT PROFIT_INT
3. Part C
   Single line file, one file per test case
   SOURCE_STRING PATTERN_STRING INDEX1 INDEX2 INDEX3...
